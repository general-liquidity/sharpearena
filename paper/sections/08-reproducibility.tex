\section{Reproducibility statement}\label{sec:repro}

The environment is a Rust workspace of three crates under the MIT and Apache-2.0 licenses, published to crates.io, npm and PyPI, with a pinned toolchain and a lockfile, depending on the published SharpeBench engine crates rather than a vendored copy. The core forbids unsafe code. The determinism claims are enforced rather than asserted: committed FNV-1a golden hashes pin the generated scenarios and the matching engine's fill tape, the WebAssembly crate's tests assert byte-identity with the native engine for both stepping and scenario generation, and the npm package's smoke test performs the replay-and-tamper check of \cref{sec:replay} on every run. The contract artifacts, schemas, conformance fixtures and the governance document, are committed beside the code they govern, and a conformance test exercises the fixtures. Continuous integration covers the Rust surface with formatting, lints as errors, tests and a WASM target build, plus dependency auditing, the npm package and the Python wheel.

Every planned number in \cref{sec:experiments} is produced by a committed script under \texttt{paper/src/} from fixed seeds, writing JSON evidence to \texttt{paper/evidence/} and figures to \texttt{paper/figures/}; the commands are listed in \cref{app:commands}. The scripts import the published Python package and call only its public API, so reproducing the evidence requires the package version pinned in \cref{app:commands} and nothing else.

No large language model is a component of the environment, the contract or any planned result. The environment has no judge. Language models were used to draft and edit prose; every bibliography entry was checked against its source.

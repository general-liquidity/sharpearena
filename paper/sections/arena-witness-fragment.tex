\subsection{Rank-eligibility witness: the acceptance set is non-empty}\label{sec:witness}

The baseline board of \cref{sec:f1} contains no rank-eligible policy, leaving open whether the conjunction can be satisfied at all. We answer by construction with an out-of-band oracle, not an entrant. For each seed, the script replays the deterministic, policy-invariant tape one bar ahead and mixes standardized next-bar truth $z_t$ with one fixed seeded noise path $\varepsilon_t$:
\[
\mathrm{signal}_t(s)=s z_t+\sqrt{1-s^2}\,\varepsilon_t,
\qquad 0\le s\le1.
\]
The same $\varepsilon_t$ is reused at every $s$ (common random numbers), so changing signal strength does not silently change the experiment. A sign-following policy trades every bar; a deadband policy trades only when $|\mathrm{signal}|>1$ and otherwise holds. Both are scored through the unchanged SharpeBench conjunction over 16 seeds. The per-seed gate uses the probabilistic Sharpe ratio (PSR), the probability under the kernel's stated sampling model that Sharpe exceeds its reference threshold. The script records the full coarse acceptance set. It refines an \emph{observed crossing bracket} by bisection only when that coarse set is monotone; otherwise it reports the observed set without calling any crossing a threshold. These are numerical brackets on the stated grid and common random numbers, not a proof that eligibility is globally monotone between unsampled strengths. All ten attained coarse series are monotone.

The result is an existence proof and a calibration, not evidence about an agent. The deadband construction is eligible on every tier, so the observed acceptance set is non-empty. The every-seed gate is last to open at all ten observed thresholds; pooled DSR and bootstrap gates open earlier. The sign follower never becomes eligible on Calm, even at $s=1$, because its every-bar turnover costs more than the low-volatility signal is worth. Thus the environment does not impose an activity requirement, but its cost model does require a Calm policy to ration turnover (\cref{fig:witness}).
